# Gothic environment art

`library_background.png` and `stone_tile.png` were generated for Politropia
with OpenAI's built-in image generation tool on 2026-09-18, then prepared for
mobile use with `tools/process_gothic_assets.py`.

Art direction: an original dark gothic castle-library in crisp pixel art,
using a near-black navy, cobalt-blue, and restrained amber palette. The user
supplied mood board was used only as a style and atmosphere reference.
